# SLRR New Age: project identity and attribution

## Short version

SLRR New Age started from an OpenSLRR DX11 fork. OpenSLRR supplied an important
technical foundation and remains a credited upstream reference. SLRR New Age is
now an independent project with its own repository, name, roadmap, code changes
and release decisions.

The accurate description is:

> SLRR New Age is an independent continuation inspired by and initially forked
> from OpenSLRR DX11.

Avoid describing the current repository as “the OpenSLRR project” or implying
that it is an official OpenSLRR release.

## What remains credited

- OpenSLRR and its contributors for the initial engine work, research and
  reference implementation: <https://github.com/EliasFD3S/openslrr/>.
- The upstream OpenSLRR documentation: <https://eliasfd3s.github.io/openslrr/>.
- Other research, tooling and third-party components listed in the README and
  their respective license files.
- Street Legal Racing: Redline and its original creators. Original game assets
  are not distributed by this repository.

## What defines SLRR New Age

The SLRR New Age identity applies to the work developed after the fork,
including the independent repository and documentation, native Vulkan/bgfx
work, performance instrumentation, frame-time diagnostics, audio failure
handling, renderer and streaming experiments, and future compatibility or
gameplay decisions. Those changes should be documented here rather than
attributed to the upstream OpenSLRR project.

## README wording

For short descriptions, use one of these formulations:

- “Independent continuation of an OpenSLRR DX11 fork.”
- “Inspired by OpenSLRR; developed independently as SLRR New Age.”
- “A modern C++ engine project for Street Legal Racing: Redline, with OpenSLRR
  credited as the initial technical foundation.”

Do not remove upstream credit in order to establish the new identity. Clear
attribution and a clear project boundary are both required.
